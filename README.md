### ⭐ Featured Project — PyVisualizer

**[PyVisualizer.dev](https://pyvisualizer.dev)** | React · TypeScript · Python · Pyodide · Web Workers

An interactive code execution visualizer that turns Python programs into step-by-step animations of data structures, algorithms, and program state.

- 🚀 Reached **100+ users within the first 24 hours** of launch.
- ⚙️ Executes Python in-browser using CPython through Pyodide and Web Workers.
- 🔍 Uses Python AST analysis to automatically recognize **6+ data structures**.
- ⏪ Supports forward and backward navigation through **1,000 execution steps**.
- 🎬 Animates linked lists, trees, graphs, matrices, heaps, pointers, and recursion.
- ✅ Backed by approximately **1,570 automated tests** across TypeScript and Python.
- 🧩 Separates execution tracing, state snapshots, layout calculations, and React rendering.
