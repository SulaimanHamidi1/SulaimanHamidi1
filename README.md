### ⭐ Featured Project

**[Code Visualizer — pyvisualizer.dev](https://pyvisualizer.dev)**
Paste any Python (including LeetCode solutions) and watch it run step by step as animated linked lists, trees, graphs, matrices, and recursion — right in your browser.

- 🚀 Drew **100+ users in its first 24 hours** after launch
- ⏪ Scrub forward and backward through up to 1,000 execution steps
- 🔍 Auto-detects 6+ data structures via static AST analysis — no annotations needed
- ✅ Backed by ~1,570 automated tests across all 83 built-in examples
- 🛠️ React · TypeScript · Pyodide · Web Workers · Framer Motion

👉 **[Try it live at pyvisualizer.dev](https://pyvisualizer.dev)**
